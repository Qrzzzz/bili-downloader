# 3.9 便携自解压候选验证

日期：2026-10-25。基线：main / v3.8 `ae7ff4f0e233c51c7f9b6a3c409be495c224b5d8`。分支：`codex/v3.9-portable-sfx`。用户随后明确授权提交并推送，并要求今后不保留 ZIP，所有应用发行包使用 EXE；本轮不创建标签或 Release。当前候选保留 `dirty=true` 标记，不作为远端 CI、attestation 或公开下载验收证据。

## 实现

- 构建官方 7-Zip 26.05 GUI 自解压 EXE，按版本目录持久解压，不在临时目录运行应用；外层不启动主程序、不安装 7-Zip、不提供卸载或事务式升级。
- 对主目录选择窗口、图标、VERSIONINFO 和 manifest 做资源修改。主窗口标题为“Bili Downloader Lite 3.9 解压”，含“解压到：”“解压”“取消”；manifest 明确 `asInvoker`、`uiAccess=false`。其余引擎进度和错误对话框仍可能为英文。
- 官方 x64 安装包中的 `7z.sfx` 实际为 x86（`IMAGE_FILE_MACHINE_I386`）；它解出的应用及发布目标仍为 Windows x64，不能据外层 PE 架构宣称应用支持 x86。
- 原始文件、引导工具及抽出的模块按固定 SHA-256 校验；通过读取上游安装包提取工具，不执行该安装包、不改变系统安装状态。仅外层模块被分发，`7zr.exe`、`7z.exe`、`7z.dll` 留在构建目录。
- 构建不再生成 ZIP 发行包。EXE 带中文使用说明、7-Zip License、完整 LGPL 文本及来源/修改说明；`payload-files.json` 记录除清单自身外所有文件的大小和 SHA-256。实际运行 EXE 解压后核对文件集合、大小和摘要；外层 SHA256SUMS 与构建来源证明负责最终资产身份。SBOM 记录外层模块版本、摘要和源码地址。
- 发布配置固定为三项资产：EXE、SBOM、SHA256SUMS，分别验证构建来源及发布摘要；未触发该工作流。校验文件只包含 EXE 和 SBOM 两个条目，发现当前版本遗留 ZIP 会拒绝生成校验文件。旧的 3.9 ZIP 候选已移入回收站。

## 仍待验收的边界

- 界面输入工具出现 `failed to activate captured window` 和 `coordinate input geometry is unavailable`；刷新后已确认目录未改变，未继续用失效坐标或其他 UI 自动化补点。最终包的已有目录覆盖提示、解压中途取消与磁盘不足/拒绝写入、应用文件占用等真实分支仍待人工验收。
- 取消或错误可能留下部分文件，不承诺回滚；建议新目录解压。没有自动删除旧版本、自动覆盖运行中的文件或自动迁移用户 FFmpeg。
- 当前未重新做真实 Bilibili 下载、手机扫码、实体读屏、高对比度、多系统/DPI、真实独立标准用户或从互联网下载后的 SmartScreen 测试。应用下载与凭据机制未改变，不把本地启动通过当成这些场景通过。
- 没有 Authenticode 代码签名；未进行第三方样本上传或宣称杀毒/SmartScreen 零告警。正式发行仍需干净提交、CI、包校验、attestation、远端摘要和授权。

## 新组件来源、许可和安全公告核对

固定 [官方 26.05 发布](https://github.com/ip7z/7zip/releases/tag/26.05)；与官方 asset digest 一致，源码和完整 LGPL 文本随负载记录。官方 [更新记录](https://www.7-zip.org/history.txt) 显示 26.05 发布于 2026-10-21，并含漏洞修复。

已核对 GitHub Security Lab 的 [GHSL-2026-115–122](https://securitylab.github.com/advisories/GHSL-2026-115_GHSL-2026-122_7-zip/) 与 [GHSL-2026-140](https://securitylab.github.com/advisories/GHSL-2026-140_7-Zip/)，公告所测版本为 26.00，披露的修复版为 26.01；此次没有采用这些旧版本。该公告核对不等于完整漏洞数据库扫描，也不能证明 26.05 无未知漏洞。路径穿越、重复项、链接、资源上限、缓存篡改和下载失败的本地回归独立保留。
