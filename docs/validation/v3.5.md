## 功能与保护边界

- 暂存扫描覆盖当前及任务使用过的目录，显示活动、可恢复、孤立、已完成、回收区与保护项的占用、任务关联及原因。新增目录登记表，移除记录与重启后仍能找到登记过的目录；旧版早已移除且没有登记的目录需先设为当前目录再扫描。
- 每次最多扫描 1000 项、20,000 个文件/目录节点。扫描失败项不计入已测量占用；达到上限、权限错误、未知项、链接及 Windows 重解析点明确保护。异常项不隐藏后续可扫描的正常项。
- 清理先获得下载器共用的逐任务暂存 OS 锁，再在 SQLite 写事务内重查任务状态、路径归属及整个树的元数据指纹。仅所选孤立/已完成暂存可同卷重命名到 `.bili-tasks-recycle`；可恢复断点、等待/在途任务与最终媒体保留。还原禁止覆盖新暂存和处理活动任务；重命名失败保留原文件并返回保护原因。成功后的空目录只用非递归 rmdir 回收。
- 暂存回收区支持重启后还原，但仍占用磁盘。应用不永久删除文件；需要释放空间时由用户打开回收区自行处理。界面与发布说明明确说明这一点。
- 阶段变化立即共享；同阶段持续进度最多每秒保存一次，本地下载回调仍有 250 ms 节流。每任务最多一个延迟计时器，零散回调停止后也补写最后进度；阶段变化、终态和关闭取消旧计时器，避免过期进度重新出现。现有两秒轮询读取共享记录并标注所属窗口；非所属窗口不能取消、重排、移除或领取在途任务。终态/重启恢复清除旧进度。
- 版本统一为 3.5 / 3.5.0.0；配置版本 1、数据库版本 1、IPC v2 和依赖锁不变。
