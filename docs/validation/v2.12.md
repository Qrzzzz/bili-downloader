## 变更与回归

- 服务入口统一从分享文本中提取完整 HTTP(S) URL 候选，再经过既有 HTTPS、官方主机、端口、用户信息、视频路径和分 P 校验。
- 覆盖标题加链接、多行、Markdown 显示文本与目标重复、`\_` / `\&` 分享参数转义、中英文包裹标点、短链、移动站、纯 BV/av、分 P 保留与追踪参数移除。
- 同一规范地址重复出现可正常解析；不同视频、不同分 P、短链与完整链接同时存在时提示只保留一个，不为去重访问网络。
- 外域、伪装域名、IP、HTTP、用户信息、自定义端口、无效视频路径、无效/重复 p、控制字符、外域 URL 路径或查询中嵌入的视频 URL，在服务回归中均未到达上游视频解析器。
- 两项生产 Backend 回归验证分享文本经 `parse.start`、服务规范化、DTO 和终态收尾，保留第二分 P。上游视频元数据使用明确的本地夹具。
