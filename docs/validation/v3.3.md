# 3.3 本地开发验证

分支：`codex/v3.3-flat-tasks`。范围为用户要求的 3.3 任务页扁平化更新。2026-09-16 用户验收通过并授权进入 Release 流程。

## 变更

- 去掉任务卡片与嵌套 Expander，使用分隔线列表、同行标题/状态及单层详情。
- 空指标折叠；原生 CommandBar 根据状态显示操作并支持窄窗口溢出。
- 文件按需读取，并发详情请求共享同一次读取；单文件直接打开，多文件逐项展示。
- 文件路径不再在分 P 成功明细中重复；失败/取消明细保留，日志在独立可滚动对话框查看和复制。
- 版本、程序集、manifest、发行工作流、测试与文档同步为 3.3 / 3.3.0.0，IPC v2 和下载机制不变。

## 发布流程

候选提交经 PR Quality checks 通过后合并 main；核对合并树一致并等待 main CI，通过后创建注释标签 v3.3。发布后通过 GitHub API 核对 tag/commit、Release 公开状态、三份资产的名称、数量、大小和 digest，无需重新下载已由工作流验收的资产。保留 Codex 非空实现提交，并验证原生作者与 Contributors 归属。
