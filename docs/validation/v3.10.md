# 3.10 添加下载页验证

日期：2026-10-27。基线：`ad74efb`（3.9 候选）；开发分支：`codex/v3.10-download-workflow`。用户授权实施下载页审计调整并作为 3.10，随后明确授权 release。下列本地结果属于未提交候选的证据，不能代替正式标签构建；正式发布按 PR、Quality checks、合并、main CI、注释标签与 Release 工作流完成。此前未独立发布的 3.9 EXE-only 分发改动一并进入 3.10。

## 实现范围

- 统一单条与批量解析入口。Enter 换行、Ctrl+Enter 解析；来源区在解析后收起，主提交按钮固定在页面底部。
- 继续添加保留已有草稿；离线规范化后跳过同来源与访问方式的已有项目。更改访问方式只影响新链接。页面上限 50 项；移除可撤销最近一项，退出不保存未入队草稿。
- 批量勾选、单项解析重试、逐项解析进度、取消后保留已成功项目。提交前显示可添加数量和画质、分 P、缺少目录的问题，仅提交所选可用项目。
- 批量特殊规格不会更新全局偏好，包括移除其他项目后只剩一项的情况。共用规格动作移至“更多”；已入队规格保持冻结。
- 宽窗口列表与编辑区并排，窄窗口独立显示列表或单项编辑；配置操作转移焦点，完成后返回列表。修复分 P 控件在绑定与选择变更交错时的同步，实际选中项与下载规格一致。
- 反馈使用页面内提示，入队后才提供任务入口；完整目录按需查看，诊断日志在独立对话框展示。
- IPC v2 增加离线 `parse.inspect`。解析缓存仍上限 100，最多保护当前 50 项及 1 项撤销记录，避免长会话中草稿标识被淘汰。没有改变下载执行、数据库、凭据存储、依赖锁或 EXE-only 分发方式。
