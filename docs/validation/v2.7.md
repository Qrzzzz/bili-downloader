| 缺失与损坏 | 解析及独立预检仍成功；需要 FFmpeg 的下载分别返回 `ffmpeg_missing` / `ffmpeg_broken`。当前目录、空/相对 PATH 不触发探测或执行。 |

## 用户提供内容的真实验收与清理

用户提供 `BV1QeNc6iE84` 并明确要求最多下载 2—3 个视频、验证后立即删除。本轮仅选择其中较短的 P46（约 460 秒）与 P49（约 649 秒）；没有全量下载 61 P。通过正常支持的 `?p=46` 链接进入，选择实际可用的严格 360p。验收针对新打包后端及真实 IPC，不代表人工点击了前端按钮。

| 场景 | 结果 |
| --- | --- |
| 多 P 下载阶段取消 | 对 P46/P49 发起批次，在首次下载进度后发送真实 `operation.cancel`；返回 cancel_requested，两 P 最终均 cancelled。清理 1 个取消片段。 |
| 受控本地失败及重试 | 隔离目录中创建真实父路径文件障碍，使两 P 返回 output_permission 且可重试；移除本地障碍后调用真实 `download.retry`，两 P 均 completed。没有模拟网络失败。 |
| P46 MP4 | AV1 视频 + AAC 音频，640×360，459.639 秒，7,191,514 字节；ffprobe 验证和 SHA-256 后立即删除。 |
| P49 MP4 | AV1 视频 + AAC 音频，640×360，648.092 秒，8,916,660 字节；ffprobe 验证和 SHA-256 后立即删除。 |
| P46 MP3 与安全取消 | MP3 单音轨，192000 bps，459.639 秒，11,033,070 字节；在 converting 阶段发送取消，收到 waiting_for_postprocessing=true，当前文件安全完成。该单 P 批次最终 completed；验证后立即删除。 |
| 凭据与清理 | 原 session 和隔离副本字节均未更改；3 个完成输出、取消片段、隔离会话/日志及整个临时目录全部已删除；后端退出码 0。只保留脱敏状态、媒体参数与摘要。 |

前两次本地验收脚本因多 P 首页只有“最高可用”选项而没有可供严格画质断言的高度，停在下载前，完成输出均为 0；第二次已保存具体上下文。改从已有 P46 链接进入后完成上述验收。`real-acceptance-attempt1/2.*` 保留这段工具前置检查记录，不把它们算作产品下载失败或成功，也没有为此修改产品解析代码。
