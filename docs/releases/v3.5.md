# Bili Downloader Lite 3.5

本版补齐暂存管理（[#40](https://github.com/Qrzzzz/bili-downloader/issues/40)）和跨窗口任务进度同步（[#38](https://github.com/Qrzzzz/bili-downloader/issues/38)）。

## 暂存占用与安全清理

“任务 → 暂存管理”扫描当前及任务使用过的下载目录，显示占用、关联任务、分类和保护原因。活动任务与可恢复断点保留；只允许多选孤立残留或已完成暂存进行清理。成功后的空暂存目录自动回收，最终媒体不受影响。

清理前重新核对任务状态、目录归属、预览变化和跨进程暂存锁。链接、Windows 重解析点、权限错误和锁定项均受保护并明确报告；扫描失败项不计入已测量占用。更换下载目录、移除记录及应用重启后仍可扫描已记录目录。旧版本已移除且从未记录过的目录，需要先将其设为当前下载目录再扫描。

清理将所选目录移入同卷 `.bili-tasks-recycle`，完整保留文件并支持还原。**这一步不会释放磁盘空间**；还原不覆盖原位置已有暂存，也不处理活动任务。还原孤立残留只恢复文件，不会重建已移除的任务记录。需要释放空间时，可在暂存管理中选择回收项并打开回收区，在资源管理器中自行删除。应用不自动永久删除断点。

## 跨窗口进度

其他窗口可以读取任务的下载、等待资源、合并、转换和校验阶段，百分比与速度也同步显示，并标注“其他窗口”。所属窗口在阶段变化时立即保存，同阶段连续进度最多每秒保存一次；沿用两秒刷新，持续进度通常在三秒内可见。非所属窗口仍不能取消、重排或移除任务。

任务结束或所属进程退出后的恢复会清除过期进度；异常退出仍需用户确认继续，不会自动恢复联网下载。原 MP4/MP3、输出校验、日志历史和账号保护契约保留；数据库版本 1、配置版本 1、IPC v2 与依赖锁保持兼容。

本地候选证据和外部验收边界见 [验证记录](../validation/v3.5.md)。
