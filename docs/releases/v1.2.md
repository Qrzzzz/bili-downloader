# Bili Downloader Lite v1.2

v1.2 是一次聚焦构建、验证与发布一致性的更新，保持现有单窗口 Lite 产品形态和功能边界。

## 替代 v1.1 的说明

公开的 `v1.1` 标签指向旧提交 `dbfc8a044a3ef5e6b83f6ea22a65c59e9279b592`，但后来合入主分支的 v1.1 源码位于 `908f91dc7f8662a7b9205c381a53f4d91c2d26ec`，因此 v1.1 的源码标签、公开二进制与主分支并不一致。

为保留公开历史，v1.1 标签和 Release 均不移动、不删除、不重写。v1.2 用新的标签、源码、PE 元数据、构建提交、资产 digest 与 GitHub artifact attestation 完整一致的发布链替代 v1.1；后续应优先使用 v1.2。

## 更新内容

- 依赖固定为 Python 3.13/Windows x64 的完整哈希锁；构建每次创建全新虚拟环境，只安装带审核 SHA-256 的 wheel。
- yt-dlp 更新到稳定版 2026.8.19，覆盖 2026-07-03 合入的 Bilibili API 解析修复，并通过真实匿名解析验证。
- PR/main 只运行确定性质量检查；定时/手动匿名公共网络 smoke 独立运行，HTTP 412 / `environment_blocked_412` 会明确失败。
- 正式发布工作流只接受 `v1.2`，并强制校验两级版本号、源码版本、标签、PE 元数据和构建提交一致。
- 发布后自动复核 Release 状态、精确标题、标签提交、资产名称/数量/大小/API digest 与 attestation。
- 对 onefile 内容进行审计并如实测量体积，不设置体积阈值。

## 发布资产

- `BiliDownloader.v1.2.exe`
- `BiliDownloader.v1.2.sbom.json`
- `SHA256SUMS`

三个资产均有 GitHub artifact attestation。可使用 `gh attestation verify <文件> --repo Qrzzzz/bili-downloader` 验证来源。

## 范围与依赖边界

- 保留 Python、PySide6、yt-dlp、PyInstaller、Playwright 和单窗口轻量形态。
- 不新增登录方式，不读取用户日常浏览器 Cookie，不增加 Playwright 能力。
- 不安装或内置 Chromium、Electron、Tauri、WebView2、QtWebEngine、后台服务或自动更新器。
- 不捆绑 FFmpeg；需要合并音视频时仍由用户自行提供合规安装。
