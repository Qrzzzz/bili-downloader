# Bili Downloader Lite 3.2

本版聚焦原生界面细节和下载队列的可见性。

- 任务入口显示数字角标，统计等待和执行中的任务；队列暂停时仍显示等待数，完成、取消或中断的记录不计入。切换页面和筛选不影响计数。
- 下载、任务、账号和设置页统一标题层级、卡片圆角和留白，任务状态以标签呈现，空列表显示明确引导。
- 没有完成记录时隐藏清理入口；清理提示明确保留已下载文件。导航的可访问名称包含任务数量。

下载方式、偏好、登录态、文件与队列持久化保持兼容，IPC 仍为 v2。

验证范围见 [验证记录](https://github.com/Qrzzzz/bili-downloader/blob/v3.2/docs/validation/v3.2.md)。

Windows x64 下载 `BiliDownloader.v3.2.win-x64.zip`，完整解压后运行 `BiliDownloader.v3.2.exe`。随包发布联合 SBOM 与 `SHA256SUMS`；FFmpeg 仍需自行准备。
