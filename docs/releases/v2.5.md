# Bili Downloader Lite v2.5

v2.5 将 Windows 界面迁移到 Microsoft 官方 **Windows App SDK / WinUI 3**。前端使用 C#/.NET 与 XAML，Python 继续负责原有下载、登录和诊断逻辑。

## 原生 Windows 界面

- 真实 WinUI `Window`、`MicaBackdrop` 与 `TitleBar`，由 Windows 管理最小化、最大化和关闭按钮。
- `NavigationView` 将下载、账号和设置组织为独立页面；切换页面保留任务、进度和结果。
- 默认 WinUI 控件、主题资源与焦点状态，支持跟随 Windows、浅色和深色偏好。
- 状态与错误使用 `InfoBar`，确认操作使用 `ContentDialog`；下载结果继续显示在主窗口内。

## 保留的核心能力

支持链接/BV/av 解析、封面、分 P 与画质选择、MP4/MP3、进度、取消、失败项重试和应用内扫码登录。yt-dlp、Bilibili URL 校验、QR 协议、Cookie 校验、DPAPI 保护、FFmpeg 查找与失败分类继续复用既有 Python 实现。

前后端通过 IPC v1 的 JSONL 标准管道通信。Python 后端不依赖 Qt；任务快照、扫码代次、取消与资源释放由后端统一管理。界面不使用 Qt、HTML、Electron 或 WebView。

## 下载与升级

下载 **`BiliDownloader.v2.5.win-x64.zip`**，完整解压后运行其中的 **`BiliDownloader.v2.5.exe`**。请保留相邻的 `BiliDownloader.Backend.exe`、运行库、资源和 `backend-runtime` 目录，不要只复制主 EXE。

包中包含 .NET、Windows App SDK 和 Python 运行时。配置与 DPAPI 登录态沿用已有存储位置及 schema；可从旧版升级。Windows x64，最低系统目标为 Windows 10 1809，Mica 效果由系统能力决定。

FFmpeg 仍由用户自行准备，放在程序相邻的 `tools/ffmpeg.exe`，或通过系统 `PATH` 中的绝对目录提供。程序不下载或捆绑 FFmpeg，不绕过平台访问限制；HTTP 412 等平台拒绝会按原有分类报告。

随附资产：

- `BiliDownloader.v2.5.win-x64.zip`
- `BiliDownloader.v2.5.sbom.json`：联合 Python、NuGet、运行时与交付文件的 CycloneDX 清单。
- `SHA256SUMS`

三个资产均由 Release 工作流生成来源证明。来源证明与 Windows Authenticode 签名不同，本版不宣称已进行 Authenticode 签名。

## 验证范围

本地记录包括 201 项 Python 测试、9 项 C# 管道检查、最终 ZIP 解压后的真实 WinUI 启动/主题/导航/关闭检查、包内容审计与依赖漏洞检查。公网二维码生成和首次等待扫码状态通过；一次真实下载收到 HTTP 412，不作为成功下载证据。

维护者已确认 v2.5 完成并授权发布。代理未采集完整手机确认登录、成功 MP4/MP3 下载、全部 DPI/高对比度和辅助技术人工验收的证据，详情见[验收记录](https://github.com/Qrzzzz/bili-downloader/blob/v2.5/docs/validation/v2.5.md)。
