# Bili Downloader Lite v3.8

3.8 补齐操作结果反馈，修复检查更新在 GitHub API 限流时不可用的问题，并让暂存管理更容易理解。

- 使用 WinUI 原生 InfoBar：成功显示绿色，警告显示黄色，错误显示红色。覆盖视频解析、批量配置及入队、任务终态、暂停/继续队列、取消/重试/移除任务、清理已完成记录、登录验证、诊断、更新、复制和打开文件或目录。
- 诊断发现问题、批量部分失败、登录无效或暂存项未处理时给出相应提示；不会把“操作返回”一律当作成功。重复任务事件和后台轮询不会重复显示同一终态提示。
- 暂存清理、还原、扫描和日志复制在弹窗内直接显示反馈。说明哪些临时文件能处理，已下载的视频或音频会保留；暂存回收区属于应用，移入后可还原，永久删除后才释放空间。
- 更新 API 不可用时，通过 GitHub 官方发行页面的跳转检查最新版；保留严格的地址和两段版本号校验。连接失败会说明原因并提供手动查看方式，未检查更新时也能打开发行页面。
- 文件、目录和浏览器操作检查系统返回值，未能打开时显示错误；复制异常也会显示错误。

配置、凭据、任务数据库和 IPC v2 保持兼容，第三方依赖锁不变。验证范围见 [3.8 验证记录](../validation/v3.8.md)。
