# Bili Downloader Lite v2.9

- 修复 #16：多实例清除或更新凭据后，解析、下载与重试不会静默改用其他代次的账号；在带凭据请求前明确提示重新解析。
- 修复 #18：扫码验证并保存成功后，账号页立即显示“已登录”，隐藏扫码入口；终态前发生取消、刷新或凭据变化时不再显示成功。
- 修复 #19：验证期间凭据被清除、损坏或替换后，返回当前状态并撤销旧解析和重试能力，不应用迟到的“已验证”。

保留匿名模式、多实例、DPAPI 存储、临时 Cookie 清理、MP4/MP3 与 FFmpeg 边界。未升级依赖或变更 IPC 版本。验证范围见 [验证记录](../validation/v2.9.md)。
