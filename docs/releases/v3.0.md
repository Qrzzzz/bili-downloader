# Bili Downloader Lite v3.0

3.0 将下载改为独立任务，并新增专门的任务页面。此文描述本地候选；是否正式发布以 GitHub Release 为准。

- 一个视频及选定分 P 组成一个任务，任务之间默认同时下载 2 个，可设置为 1—3 个；任务内的分 P 依次下载。
- 下载时仍可继续解析和添加视频。任务页集中展示状态、进度、规格、逐 P 结果、输出文件和独立日志，提供筛选、取消、失败重试、继续未完成项及队列排序。
- 新增批量解析：一次处理最多 50 个链接、BV/av 号或分享文本，单项失败不阻断其余项目；可统一加入，也可逐项选择分 P。默认只选链接指向的分 P，不自动下载整部课程。
- 任务先保存再确认加入；重复提交不会重复创建。重启保留记录，未完成任务需要确认后继续，不自动联网。
- 暂停队列停止启动新任务，已执行任务继续完成。移除任务记录与清理已完成记录均保留媒体文件。
- 输出文件按任务暂存、验证后原子发布；多个任务/窗口协调同名输出、磁盘预算和 FFmpeg 处理，不覆盖已有文件。
- 保留严格画质、192 kbps MP3、完整解码验证、凭据代次、匿名模式、安全取消和退出收尾。账号改变后原任务需要重新确认，不静默切换账号或降低画质。
- 前后端同步升级为应用 3.0 / IPC v2，不新增第三方运行时依赖，沿用 WinUI 3 单窗口与原生主题。

任务记录存在本机 SQLite 中，不保存 Cookie 或临时媒体地址。中间文件位于下载目录的 `.bili-tasks` 子目录，取消后保留供继续使用。任务并行数按窗口生效；合并、转码和解码校验在本机实例间串行处理。

详见 [协议与架构](../architecture/ipc-v2.md) 和 [验证记录](../validation/v3.0.md)。
