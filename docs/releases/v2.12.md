# Bili Downloader Lite v2.12

本版本增加从分享文本中直接提取 Bilibili 视频链接的能力。

- 可直接粘贴“标题 + 链接”、多行分享文本或 Markdown 链接，再点击“解析”或按回车，无需手工删除标题和括号。
- 支持标准视频链接和 `b23.tv` 短链；纯 BV / av 号继续可用。
- 自动去掉链接周围的常见中英文标点，兼容分享参数中的 Markdown 转义；保留 `p` 分 P 参数，移除分享追踪参数。
- 同一链接重复出现时自动去重；多个不同链接或不同分 P 同时出现时，提示只保留一个。短链与完整链接不会联网判断是否为同一个视频。
- 输入框支持多行和自动换行，仍在原有下载页面完成解析与下载。

提取出的链接继续经过原有 HTTPS、官方主机、端口、用户信息和视频路径检查，短链重定向仍逐跳校验。未增加运行时依赖，IPC 与配置格式保持兼容。

验证结果见 [2.12 验证记录](../validation/v2.12.md)。
