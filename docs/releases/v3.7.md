# Bili Downloader Lite v3.7

3.7 修复真实任务验收报告在重试后未检查最终媒体的缺口，并补齐持久并行任务的实际恢复证据。生产下载执行机制、任务数据库、配置和 IPC v2 保持兼容，依赖锁不变。

- 并行验收报告保留首次状态、失败与最终结果；重试后重新检查文件规格、FFprobe、完整解码和 SHA-256。通过必须确实观察到两个活动任务。
- 新增显式 opt-in 的隔离真实来源验收工具，覆盖 MP4/MP3、单/两个分 P、取消继续和实际下载中终止 Python 进程后恢复。多分 P 在 P1 成功后中断 P2，恢复后核对 P1 文件摘要保持一致。
- 基于 3.6 生产源码的双任务、实际失败重试及上述生命周期验收已通过；这些是源码后端证据，不伪称为 3.7 发行包的重新公网下载验收。首轮 MP3 的 `output_permission` 底层原因尚未确定，重试成功不代表已修复未知原因。
- 核对 #43 的 3.4–3.6 功能及发行计划已实施。#42 的手机扫码、文件关联、系统剪贴板、实体读屏和高对比度仍等待人工结论，保持开放。

发布验证见 [3.7 验证记录](../validation/v3.7.md)；真实来源、终态和脱敏 JSON 见 [真实任务补充验收](../validation/v3.6-external.md)。本版本不修改现有发布门槛，不关闭 TLS 校验或绕过平台拒绝。
