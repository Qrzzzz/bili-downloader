# Bili Downloader Lite v2.2

v2.2 新增仅音频 MP3 下载，同时保持 v2.1 的音视频 MP4、分 P、登录、重试、取消和安全边界。

## 新功能

- 下载选项新增“仅音频（MP3）”，选取最佳可用音轨，并通过用户自行提供的外置 FFmpeg 转换为 192 kbps MP3。
- 仅音频模式下自动收起视频清晰度，并将主操作显示为“下载音频”。
- 保留单 P/多 P 选择、下载进度、逐项结果和失败项重试；重试不会丢失仅音频模式。

## 预检与任务生命周期

- 开始下载前逐分 P 预检音轨；任意分 P 没有可用音频时，整个批次都不会开始下载。
- 磁盘空间预检按音频流估算，不再计入未下载的视频流。
- 进度明确区分“下载”与“转换 MP3”。如在 FFmpeg 处理期间取消，程序会等待当前文件安全结束，不强制终止 FFmpeg。

## 实际验收

- 自动化回归覆盖 MP3 参数、音轨预检、空间估算、转换进度、安全取消、默认 MP4 兼容与失败重试。
- 使用公开单 P Bilibili 视频进行真实下载，成功生成仅含一条 MP3 音频流、码率 192000 bps 的文件；匿名请求遇到 HTTP 412 时保持失败关闭，之后按应用既有受保护登录态的正常路径完成验收。

## 发布资产

- `BiliDownloader.v2.2.exe`
- `BiliDownloader.v2.2.sbom.json`
- `SHA256SUMS`

三个资产均应有 GitHub artifact attestation。可使用 `gh attestation verify <文件> --repo Qrzzzz/bili-downloader` 验证来源。

## 范围与边界

- 没有新增运行时依赖；保持 Python 3.13、PySide6、yt-dlp、PyInstaller 和 Windows x64 原生单窗口形态。
- 不下载、安装或捆绑 FFmpeg，不修改系统 `PATH`，不从任意当前工作目录执行 FFmpeg。
- 不改变二维码登录、登录态存储、会员/付费/地区/DRM 边界，也不读取日常浏览器 Cookie。
- 已公开的旧版标签和 Release 是不可变历史，不得移动、覆盖或删除。
