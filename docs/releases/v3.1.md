# Bili Downloader Lite v3.1

3.1 记住下载模式与偏好画质，减少重复设置。

- 自动保存下载页主动选择的 MP4 / MP3 模式与画质，下次打开应用继续使用。
- “设置 → 下载偏好”可调整模式和偏好画质，也可关闭自动记忆。关闭后下载页选择仅用于本次会话，下次启动使用设置中保存的值。
- 支持“最高可用画质”与指定分辨率。指定画质不可用时提示重新选择，不自动降档，也不把自动选择写回偏好。
- MP3 隐藏画质选择并保留视频画质偏好，切回 MP4 后继续使用。
- 批量添加逐个匹配偏好，画质不可用的项目保留提示，其他有效项目可以加入；修改设置不改变已入队任务的规格。
- 兼容旧配置；非法偏好字段独立恢复默认值。快速连续切换、设置草稿与自动记忆同时操作时保留最新选择；保存失败保留原有配置。

应用及发行版本为 3.1，IPC 继续使用 v2，不新增第三方依赖。

验证边界：Python 回归、真实 C# / Python 管道及原生界面检查详见验证记录。本版未改变媒体下载、登录与 FFmpeg 执行逻辑，未重新执行公网媒体或手机扫码验收；3.0 记录的本机 TLS 下载失败不因本版偏好检查通过而视为解决。正式组包、package smoke、归档审计、SBOM、三份发行资产的来源证明和上传摘要核验由 Release 工作流完成。

详见 [协议说明](https://github.com/Qrzzzz/bili-downloader/blob/v3.1/docs/architecture/ipc-v2.md) 和 [验证记录](https://github.com/Qrzzzz/bili-downloader/blob/v3.1/docs/validation/v3.1.md)。
