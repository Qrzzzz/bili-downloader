# Bili Downloader Lite v2.6

2.6 对 2.5 的 WinUI 3 界面做整体打磨，保留原生窗口和既有下载能力。

- 下载页采用紧凑视频摘要、自适应规格区与同行目录操作，主按钮更明确；窄窗口继续使用可滚动的单列布局。
- 下载期间锁定链接，解析中的输入修改仍能使迟到结果失效。账号、诊断和更新任务不会显示成下载进度。
- 合并、转码和安全取消提供对应提示，取消请求不重复提交；跨页保留任务和结果。
- 单文件结果直接显示文件名，多文件使用文件名选择器，完整路径仍可查看；无文件时不显示空控件，逐 P 失败原因和重试保留。
- 账号页按真实登录状态显示操作；隐私说明可展开。设置草稿跨页保留，外观即时预览，保存中防重复提交，失败后保留草稿并恢复已保存外观。
- 三页统一采用 WinUI 主题资源、卡片层次与间距；修复限宽滚动容器导致的横向裁切。

应用版本为 2.6；Windows App SDK 2.4.0、.NET SDK 10.0.400、Python 3.13、IPC 1、配置 schema 1 保持原有版本。没有增加运行时依赖或改变平台访问、DPAPI、FFmpeg 与授权内容边界。

下载 `BiliDownloader.v2.6.win-x64.zip` 并完整解压，运行 `BiliDownloader.v2.6.win-x64/` 中的 `BiliDownloader.v2.6.exe`；请保留相邻后端和运行库。包内包含 .NET、Windows App SDK 和 Python 运行时；FFmpeg 仍由用户自行准备。

发行资产包括应用 ZIP、`BiliDownloader.v2.6.sbom.json` 和 `SHA256SUMS`，由精确标签的干净提交构建，并验证来源证明。EXE 未进行 Authenticode 签名。

本地已通过 201 项 Python 回归、9 项 C# 管道检查、20 项前端状态回归及原生窗口验收；本轮未补测真实手机扫码、成功 MP4/MP3 下载和完整辅助技术验收。检查结果和证据范围见 [v2.6 验收记录](https://github.com/Qrzzzz/bili-downloader/blob/v2.6/docs/validation/v2.6.md)。
