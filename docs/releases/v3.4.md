# Bili Downloader Lite 3.4

- 恢复任务前重新检查历史成功文件：存在、媒体规格、完整解码。失效输出不再被计为成功；继续未完成项可补下载，有效文件不重复下载，也不覆盖其他文件。重试失败项保持原轮次失败项范围。
- 任务日志按执行轮次保留最近 5 轮，每轮最多 16,000 字符。日志窗口可选择轮次，显示时间、状态与截断提示，复制当前选择的内容；旧数据库的最后一轮日志保留为旧记录，敏感信息继续脱敏。
- 启动真实双任务 MP4/MP3 验收；公网与人工依赖范围分别记录，未完成项目不视为通过。
