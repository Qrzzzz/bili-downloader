# Bili Downloader Lite v1.3

v1.3 的唯一核心主题是把扫码登录改为应用内原生二维码流程，并从运行时、构建和发布包中完整移除浏览器自动化依赖。下载、分 P、清晰度、失败重试、日志、诊断和手动更新检查的对外行为保持稳定。

## 主要变更

- 程序直接请求 Bilibili 官方网页扫码协议，并用 Segno 在本地生成清晰 PNG；不启动 Edge/Chrome，不读取日常浏览器 Cookie。
- 准确呈现等待扫码、已扫码待手机确认、过期/刷新、成功、取消、超时、网络失败、HTTP 412 和协议异常。
- 登录 Cookie 先过滤并通过 Bilibili NAV API 验证，只有服务端确认有效后才会用 DPAPI 原子替换本地 session。任何失败都保留原有登录态。
- 保持 v1.2 canonical session schema 可读，继续支持旧明文凭据的一次性安全迁移与旧 profile/cache 清理。
- 从锁文件、PyInstaller spec、package smoke 和发布归档中移除 Playwright/driver/Node，并强化 Chromium、Electron、FFmpeg、profile、凭据和日志禁入审计。

## 发布资产

- `BiliDownloader.v1.3.exe`
- `BiliDownloader.v1.3.sbom.json`
- `SHA256SUMS`

三个资产均应有 GitHub artifact attestation。可使用 `gh attestation verify <文件> --repo Qrzzzz/bili-downloader` 验证来源。

## 范围与已知边界

- 保持 Python 3.13、PySide6、yt-dlp、PyInstaller 和 Windows x64 单窗口形态。
- 不包含 Electron、Tauri、WebView2、QtWebEngine、后台服务、自动更新器、Chromium 或 FFmpeg。
- Bilibili 的未公开网页扫码协议可能变化。未知 schema/状态/来源会 fail closed，并需通过独立公共网络 smoke 留证后评估。
- 真实手机扫码与账号登录需用户参与，是发布前独立人工 Gate；匿名协议探测不代表该 Gate 已通过。
