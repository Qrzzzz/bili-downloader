# Bili Downloader Lite 3.10

本版整理添加下载页，并首次正式提供中文图形自解压 EXE。

添加下载页现在使用一个解析入口。粘贴一个或多个链接后，来源区自动收起，规格与提交操作成为页面主体。Enter 换行，Ctrl+Enter 解析；提交按钮固定在底部。

批量项目可以勾选、移除并撤销最近一次移除，解析失败可以单项重试。继续添加链接、更改新链接的访问方式不会清空现有草稿；相同链接与访问方式跳过重复解析，取消解析保留已经完成的项目。页面最多保留 50 项，未入队草稿仅在当前会话保留。

宽窗口并排显示列表与单项编辑区，窄窗口在两者之间切换。入队前显示可添加数量及需要处理的画质、分 P、目录问题，只添加勾选且可用的项目。批量中的单项规格修改不再影响全局下载偏好，应用共用规格的动作位于“更多”。

解析和入队结果使用页面内提示，入队后才提供任务入口；诊断日志按需打开。已入队任务的规格、并行调度、取消、恢复与文件处理机制不变。

下载 `BiliDownloader.v3.10.win-x64.exe`，选择新的可写目录解压，再运行解出的 `BiliDownloader.v3.10.exe`。解压器不安装、不自动启动应用；以后直接运行目录中的程序。取消或失败可能留下部分文件，应换用空目录重新解压。用户自行准备的 FFmpeg 需放入新目录的 tools 文件夹或配置到绝对 PATH。

只提供 EXE 应用包、SBOM 和 SHA256SUMS。负载清单记录大小与 SHA-256，发行工作流验证实际解压结果及三份资产的构建来源。版本为 3.10，程序集为 3.10.0.0；IPC v2 增加离线输入识别请求，原有配置和任务数据库兼容。

下载页专项验收、Python 回归和管道测试已通过；全量原生回归中的系统剪贴板检查仍待复验，实际键盘、实体读屏、高对比度及真实公网下载未在本轮完成。具体证据与边界见 [验证记录](https://github.com/Qrzzzz/bili-downloader/blob/v3.10/docs/validation/v3.10.md)。
