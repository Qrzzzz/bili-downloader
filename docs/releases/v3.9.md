# Bili Downloader Lite v3.9（本地候选）

3.9 增加一次解压、长期使用的便携自解压 EXE。从 3.9 起只提供 EXE 应用包，不再生成或上传 ZIP。本地候选尚未发布到 GitHub；正式可用版本以 Releases 页面为准。

下载 `BiliDownloader.v3.9.win-x64.exe` 后，选择可写目录并点击“解压”。打开生成的 `BiliDownloader.v3.9.win-x64` 文件夹，运行其中的 `BiliDownloader.v3.9.exe`。外层 EXE 只解压文件，之后不再需要反复运行它；不会安装软件、创建卸载项或自动启动应用。

- 主目录选择窗口已中文化。解压引擎使用官方 7-Zip 26.05 GUI SFX，保留上游进度和错误处理；其他引擎提示仍可能是英文。
- 解出的应用包含原来的 WinUI、.NET 和 Python 运行时。包内文件清单记录文件大小和 SHA-256，构建验证实际运行自解压 EXE 后逐项核对结果。
- 配置、登录凭据、任务记录和下载目录保持原有位置。请解压到新目录，不要覆盖正在运行的版本。用户自行提供的 `tools/ffmpeg.exe` 需要自行复制，应用仍不捆绑 FFmpeg。
- 取消、磁盘不足、权限或文件占用错误可能留下部分文件。请换用空目录重新解压；不要运行未完整解出的文件。本版本不提供事务式覆盖升级、自动清理旧目录或自动复制 FFmpeg。
- 外层 EXE 使用本项目图标及 3.9 版本信息；SHA256SUMS 覆盖 EXE、SBOM。发行工作流配置为验证三项资产的构建来源及上传摘要。

采用自解压格式不会自动获得 Windows Authenticode 签名或 SmartScreen 信誉。验证结果和剩余人工项目见 [3.9 验证记录](../validation/v3.9.md)。
