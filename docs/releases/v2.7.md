# Bili Downloader Lite v2.7

v2.7 从 v2.6 的 `ef57a570a236b02f070d94f94adb989e86883ed5` 开发，仅修复两个 P1 安全边界问题。P1 不代表已发现真实攻击事件。

- [#12](https://github.com/Qrzzzz/bili-downloader/issues/12)：NAV 登录验证保留 Cookie 的域、路径、Secure 和有效期，只向官方 HTTPS NAV 端点发送凭据，拒绝所有重定向及异常最终来源；失败不覆盖既有登录态。
- [#13](https://github.com/Qrzzzz/bili-downloader/issues/13)：解析、格式预检、MP4 合并和 MP3 转换统一使用受控 FFmpeg 位置，覆盖 ffprobe 和 yt-dlp 内部默认探测回退。没有可用 FFmpeg 时仍可解析，下载保留缺失/不可用的错误分类。

应用版本为 2.7；WinUI 3、.NET 10、Python 3.13、IPC 1、配置 schema 1 和 DPAPI 存储格式不变。未升级依赖，不包含 UI 改版或 #14—#19 的后续修复。FFmpeg 由用户自行提供，不安装或捆绑。

应用资产名称为 `BiliDownloader.v2.7.win-x64.zip`，完整解压后运行 `BiliDownloader.v2.7.exe` 并保留相邻后端及运行库。标签为 `v2.7`，Release 标题为 `Bili Downloader Lite v2.7`，SBOM 名称为 `BiliDownloader.v2.7.sbom.json`。

验证结果及人工缺口见 [v2.7 验收记录](../validation/v2.7.md)。正式资产由注释标签工作流从干净提交构建，并经组包检查、SBOM、摘要、来源证明和远端状态核验；本地 dirty 候选、合成媒体以及二维码首次等待态均不能替代这些证据或真人扫码验收。
