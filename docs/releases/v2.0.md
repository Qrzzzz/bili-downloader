# Bili Downloader Lite v2.0

v2.0 聚焦“更少的默认信息，更清楚的任务阶段”。它保留原生 PySide6 的舒适观感和既有下载、登录、安全边界，将主窗口从功能面板堆叠改为单一任务流程。

## 主要变更

- 初始界面只显示链接、解析、账号状态和一句引导；视频信息、分 P、画质、保存目录、进度与结果按当前阶段出现。
- 单 P 不再展示冗余选集；多 P 使用选择摘要和限高列表。账号动作互斥，诊断、日志与隐私说明进入“更多”。
- 任务详情默认折叠但继续完整记录；下载进度显示简短文件名，完整路径保留在提示中。
- 单 P、单输出成功使用紧凑结果页；多输出、多 P、失败、取消与重试继续使用完整明细表。
- 环境诊断区分本地检测与手动 GitHub 更新检查，打开诊断窗口本身不会联网。

## 生命周期修复

- 关闭等待期成为最高优先级终态，迟到的下载回调不会重新启用界面或恢复下载态。
- 下载中修改链接继续保留当前任务进度与取消入口，同时立即撤销旧链接的再次下载能力。
- 下载期间阻止新的解析，并忽略迟到的解析结果，避免并发状态覆盖当前任务。
- 下载结果已经产生、但线程引用尚未清理的窄竞态不会再把界面退回“下载中”。

## 发布资产

- `BiliDownloader.v2.0.exe`
- `BiliDownloader.v2.0.sbom.json`
- `SHA256SUMS`

三个资产均应有 GitHub artifact attestation。可使用 `gh attestation verify <文件> --repo Qrzzzz/bili-downloader` 验证来源。

## 范围与边界

- 没有新增运行时依赖；保持 Python 3.13、PySide6、yt-dlp、PyInstaller 和 Windows x64 原生单窗口形态。
- 不包含 Electron、Tauri、WebView2、QtWebEngine、Playwright、Chromium、Pillow、后台服务、遥测或内置 FFmpeg。
- 不改变二维码登录协议、登录态存储、下载权限、会员/付费/地区/DRM 边界，也不读取日常浏览器 Cookie。
- 已公开的 v1.1、v1.2、v1.3 与 v1.4 标签和 Release 是不可变历史，不得移动、覆盖或删除。
