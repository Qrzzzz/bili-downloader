# Bili Downloader Lite v1.4

v1.4 是“隐私与稳定性收口版”。它以已发布 v1.3 为基线，集中处理旧凭据残留、onefile 外置 FFmpeg、b23/封面网络边界和多实例崩溃标记，不增加下载内核或产品功能。

## 主要变更

- canonical session 通过 DPAPI 解密与结构验证后，精确清理应用自有的旧明文凭据和 profile/cache；损坏 canonical、部分失败与并发使用均保持 fail safe。
- lease、原子临时文件和历史隔离残留使用精确命名、owner marker 和年龄条件清理，活跃 lease 不会被其他实例删除。
- onefile 优先发现 EXE 相邻 `tools\ffmpeg.exe`，并明确区分 `_MEIPASS` 与用户可见 EXE 目录；不下载、不捆绑、不修改系统 PATH。
- b23 改为手工逐跳验证 301/302/303/307/308，拒绝循环、超限、HTTP 降级、外域、私网/IP、userinfo、异常端口和畸形 Location。
- 封面只从 Bilibili/官方 CDN HTTPS 来源以 streaming 下载，具有有限超时、图片类型、声明长度和实际 5 MiB 硬上限；封面失败不影响视频解析结果。
- 每实例崩溃 marker 使用版本化 JSON、原子写入和 Windows PID + 进程创建时间。保持允许多开，正常退出只删除本实例 marker。

## 发布资产

- `BiliDownloader.v1.4.exe`
- `BiliDownloader.v1.4.sbom.json`
- `SHA256SUMS`

三个资产均应有 GitHub artifact attestation。可使用 `gh attestation verify <文件> --repo Qrzzzz/bili-downloader` 验证来源。

## 范围与边界

- 没有新增运行时依赖；保持 Python 3.13、PySide6、yt-dlp、PyInstaller 和 Windows x64 单窗口形态。
- 不包含 Electron、Tauri、WebView2、QtWebEngine、Playwright、Chromium、Pillow、后台服务、遥测或内置 FFmpeg。
- v1.1、v1.2、v1.3 的公开标签与 Release 是不可变历史，不得移动、覆盖或删除。
