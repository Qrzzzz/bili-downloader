# Bili Downloader Lite v2.1

v2.1 是一次窄范围兼容性更新，修复部分视频解析成功但封面无法显示的问题，并保持 v2.0 的界面、下载、登录与安全边界不变。

## 修复

- 兼容 Bilibili 视频信息 API 返回的官方 CDN `http://` 封面地址。
- 只有无 userinfo、无自定义端口且主机属于既有 Bilibili/官方 CDN 允许列表的地址，才会在发起任何请求前升级为 HTTPS。
- 外域、IP、含凭据或自定义端口的 HTTP 地址继续拒绝；程序不会通过明文 HTTP 下载封面。
- 保留连接/读取超时、手工重定向、Content-Type、Content-Length、streaming 实际 5 MiB 上限，以及封面失败不影响视频解析结果的行为。

## 发布资产

- `BiliDownloader.v2.1.exe`
- `BiliDownloader.v2.1.sbom.json`
- `SHA256SUMS`

三个资产均应有 GitHub artifact attestation。可使用 `gh attestation verify <文件> --repo Qrzzzz/bili-downloader` 验证来源。

## 范围与边界

- 没有新增运行时依赖；保持 Python 3.13、PySide6、yt-dlp、PyInstaller 和 Windows x64 原生单窗口形态。
- 不改变下载、二维码登录、登录态存储、会员/付费/地区/DRM 边界，也不读取日常浏览器 Cookie。
- 已公开的 v1.1、v1.2、v1.3、v1.4 与 v2.0 标签和 Release 是不可变历史，不得移动、覆盖或删除。
