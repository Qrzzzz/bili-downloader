# Bili Downloader Lite 3.3

任务页改为紧凑列表与单层详情，减少重复背景、边框和空白。标题与状态同行，进度和错误按需显示。

- 已完成或部分完成任务提供文件入口；单文件直接打开，多文件展开列表逐项打开。
- 保存位置与文件名分开显示，失败分 P 保留具体原因。
- 与当前状态无关的操作隐藏，次要操作放入更多菜单；窄窗口使用原生命令栏溢出。
- 任务日志在独立对话框查看与复制，不再嵌套折叠面板。

保留队列角标、筛选、取消、恢复、重试、账号确认与记录移除语义；只移除记录，不删除下载文件。IPC v2 与依赖不变。

验证范围见 [本地验证记录](../validation/v3.3.md)。
