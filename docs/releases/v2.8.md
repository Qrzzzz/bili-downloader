# Bili Downloader Lite v2.8

v2.8 从已发布 v2.7 的 `e9986d5cf82ff82d6a92691201a6f8991cebb3c1` 开发，范围仅限 [#14](https://github.com/Qrzzzz/bili-downloader/issues/14)、[#15](https://github.com/Qrzzzz/bili-downloader/issues/15) 与 [#17](https://github.com/Qrzzzz/bili-downloader/issues/17)。本版修复输出规格复用、legacy durl 兼容和畸形 IPC 终态收尾，不扩展到其他登录或二维码议题。

- #14：输出文件名加入音视频/音频模式与严格画质身份，例如 `[video-mp4-1080p]`、`[video-mp4-best]`、`[audio-mp3-192k]`。相同规格继续使用稳定路径完成断点续传、失败重试和正常已有结果复用；已有完整文件须通过受控 FFprobe/FFmpeg 验证。不匹配或损坏的同名文件不会被覆盖或删除，应用改用带序号的新名称。
- #15：真实 Bilibili legacy durl 合流 MP4 即使未提供具体 codec，也能按提取器原始格式来源通过 MP4/MP3 预检和正确的大小估算。普通 codec 未知格式、显式无音轨、纯视频以及缺少目标高度仍不会被宽泛接纳；DASH 分离音视频继续按配对处理。
- #17：WinUI 前端在发布终态事件或移除 operation 前完整验证 completed/failed/cancelled。损坏终态、非法序号、连接断开或同时发生的管道写入关闭会让所有待响应和已接受调用明确失败或取消，避免 ApplicationSession 的 Busy/finally 与安全关闭永久等待；正常终态、重复/迟到过滤和 IPC v1 顺序契约保持不变。

应用版本为 2.8；WinUI 3、.NET 10、Python 3.13、IPC 1、配置 schema 1、DPAPI 存储及 v2.7 的 Cookie/NAV 和 FFmpeg 选择边界不变。没有升级依赖，没有 UI 改版，不自动安装或捆绑 FFmpeg；#16、#18、#19 留给后续版本。

正式资产名称为 `BiliDownloader.v2.8.win-x64.zip`、`BiliDownloader.v2.8.sbom.json` 与 `SHA256SUMS`，主程序为 `BiliDownloader.v2.8.exe`，标签为 `v2.8`，Release 标题为 `Bili Downloader Lite v2.8`。正式资产只由精确标签的干净提交构建；开发阶段的本地 dirty 候选不属于正式资产。

已经取得的本地证据、合成边界和仍待人工执行的外部下载见 [v2.8 验证记录](../validation/v2.8.md)。
