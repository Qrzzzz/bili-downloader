# Bili Downloader Lite v2.4 候选说明

v2.4 重写主窗口 UI，参照 Microsoft 的 [Windows 应用结构](https://learn.microsoft.com/en-us/windows/apps/develop/ui/windows-app-sdk-app-structure)，以标题栏、导航和内容区组织操作。当前为本地候选版，尚未发布到 GitHub Releases。

## 界面与操作

- **下载**：粘贴链接或 BV / av，解析后显示视频、分 P、格式与保存目录；运行中突出进度和取消，完成后在同一页显示结果与失败重试。
- **账号**：集中管理二维码登录、退出、清除登录态及登录与隐私说明。解析或下载时暂停账号状态变更。
- **设置**：提供跟随系统、浅色和深色主题、默认目录、环境诊断与错误日志。主题与目录分别保存，兼容旧配置。
- 错误与任务状态显示在内嵌提示中；切换页面保留任务和结果，可通过“查看下载”返回。任务详情仍可展开查看。
- 窄窗口收起导航文字；页面可滚动，高对比度模式采用系统配色。

## 技术与兼容

继续使用 Python 3.13、PySide6、yt-dlp 和 PyInstaller。Windows 标题栏扩展到客户区，同时保留系统窗口按钮、边框与菜单；本版使用实色主题背景，不包含 Mica 材质。

没有新增运行时依赖，MP4 / MP3、二维码登录协议、DPAPI 凭据保护、外置 FFmpeg、取消和安全关闭等契约保持不变。下载结果继续作为主窗口子控件，单 P 紧凑结果与多 P / 失败明细均保留。

同一候选包含 CI 与 Gate 精简：PR/main 执行回归，正式构建及产物验证集中在 Release；真实扫码、下载、界面和许可证复核按相关改动触发，公网探测仅用于手动诊断。

## 验收范围

自动验证覆盖旧配置兼容、主题持久化、跨页任务状态、内嵌错误、结果收起、取消及关闭优先级；窗口截图使用合成视频数据，不代表实际联网下载或扫码验收。

本轮界面改动需要人工检查真实手机扫码，以及标题栏拖动、贴靠、系统菜单和实际显示设置下的可读性。相关检查完成前不记为人工通过，也不启动正式发布。

本地候选文件为 `BiliDownloader.v2.4.exe`。未来正式发布使用同名主程序、`BiliDownloader.v2.4.sbom.json` 和 `SHA256SUMS`；正式资产须绑定精确源码提交，不能复用带 dirty 标记的候选包。
