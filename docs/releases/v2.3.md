# Bili Downloader Lite v2.3

v2.3 将下载结果从独立弹窗移入主窗口，让解析、下载、结果确认和失败重试保持在同一个任务流中。

## 主窗口内嵌结果

- 下载结束后，结果直接显示在“任务状态”下方，不再创建独立的下载结果窗口。
- 单 P、单输出且成功时继续使用紧凑视图，显示视频、下载规格、任务汇总和保存文件。
- 多输出、多 P、失败或取消时继续显示完整明细表，保留每个分 P 的状态、输出和错误信息。
- 保留“打开文件”“打开所在目录”“重试失败项”，并用“收起结果”释放主窗口空间。

## 生命周期与兼容

- 重试仍复用原下载请求和下载模式，重试结果会在同一内嵌区域合并更新。
- 链接变化后旧结果仍可查看和打开文件，但旧任务的失败项重试会被禁用。
- 开始新下载时收起上一任务结果；新任务结束后在相同位置展示最新结果。
- 保持 v2.2 的音视频 MP4、仅音频 MP3、分 P、二维码登录、严格清晰度、安全取消和外置 FFmpeg 边界。

## 发布资产

- `BiliDownloader.v2.3.exe`
- `BiliDownloader.v2.3.sbom.json`
- `SHA256SUMS`

三个资产均应有 GitHub artifact attestation。可使用 `gh attestation verify <文件> --repo Qrzzzz/bili-downloader` 验证来源。

## 范围与边界

- 没有新增运行时依赖；保持 Python 3.13、PySide6、yt-dlp、PyInstaller 和 Windows x64 原生单窗口形态。
- 不下载、安装或捆绑 FFmpeg，不修改系统 `PATH`，不从任意当前工作目录执行 FFmpeg。
- 不改变二维码登录、登录态存储、会员/付费/地区/DRM 边界，也不读取日常浏览器 Cookie。
- 已公开的旧版标签和 Release 是不可变历史，不得移动、覆盖或删除。
